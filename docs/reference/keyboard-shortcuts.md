# Keyboard shortcuts

These work on a board. They pause while you're typing in a field or have a dialog open. Press `?` on a board to see
them there, or choose **Keyboard shortcuts** from the **Board** menu.

| Key | What it does |
| --- | --- |
| `Alt+↑` / `Alt+↓` (`⌥` on a Mac) | Move the focused card one place up or down in its column |
| `M` | Pick up the focused card to move it with the arrow keys (see below) |
| `N` | New card in the column you're in (the last column you used, or the first open one) |
| `Space` | Expand or collapse the focused card |
| `Enter` | Open the focused card in full view |
| `E` | Edit the focused card's title |
| `Esc` | Close or cancel; leave focus mode |
| `Cmd+Z` / `Ctrl+Z` | Undo the last change |
| `F` | Focus on the column you're in, or leave focus |
| `/` | Filter cards by title or label |
| `?` | Show the shortcuts |

## Moving cards without a mouse

Tab to a card and press `M` to pick it up. Use the arrow keys to move it, between columns as well as within one, then
press `M`, `Space` or `Enter` to drop it, or `Esc` to put it back. Each step is announced to screen readers. Every card
also has **Move up**, **Move down** and **Move to…** in its menu; **Move to…** can move it to another board.

## On the board list and in Settings

| Key | What it does |
| --- | --- |
| `Esc` | In Settings: go back to the board you came from |
