# Artwork sources

Every image here and in `web/public/` must be original or public domain
(docs/DESIGN.md §0.2). Record each one below.

All of the artwork below is original, made for this project by the maintainer
(2026) with AI image-generation tools, and is licensed with the project
(Apache-2.0). The banners' lettering is Comfortaa (SIL Open Font License 1.1),
converted to outlines; no font file is shipped.

| File | What it is |
|---|---|
| `mark.svg` | Full-color butterfly mark, transparent background |
| `mark-small.svg` | Simplified mark for 16–32 px; also `../public/favicon.svg` and the header logo |
| `mark-mono.svg` | Single-color silhouette (`currentColor`) |
| `icon-maskable.svg` | Mark on a full-bleed cream square within the PWA safe zone |
| `empty-state.svg` | Line-art butterfly on a coneflower (`currentColor`) for empty states |
| `flutter.svg` | Tiny butterfly with separate wing groups, for the completion flutter |
| `../../docs/images/banner-light.svg`, `banner-dark.svg` | README banners (mark plus wordmark and tagline) |
| `../public/*.png` | Rendered from the SVGs above by `scripts/render-icons.mjs` |
